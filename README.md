# 🎯 Corporate Bingo

Открывай на следующем митинге и отмечай фразы по мере их появления. Первый, кто закрыл ряд — может уходить.

**[Играть →](https://khalidmustafin.github.io/corporate-bingo/)**

---

## Как это работает

Карточка 5×5 с корпоративными фразами. Слышишь на созвоне — нажимаешь. Закрыл ряд, столбец или диагональ — бинго.

Каждый раз карточка новая, так что у всех участников встречи она будет разной.

## Фичи

- 🇷🇺 / 🇬🇧 Русская и английская версии
- 🎲 60+ фраз в пуле — карточка каждый раз рандомная
- 🔒 Секретный режим с карточками под конкретные компании (попробуй угадать кодовое слово)
- 🌙 Светлая и тёмная тема автоматически
- 📱 Работает на телефоне

## Запустить локально

Просто открой `index.html` в браузере. Никаких зависимостей, никакого сервера.

```bash
git clone https://github.com/khalidmustafin/corporate-bingo.git
cd corporate-bingo
open index.html
```

## Задеплоить свою версию

1. Форкни репозиторий
2. Открой `index.html` и отредактируй фразы под свою компанию
3. Включи GitHub Pages: Settings → Pages → Source: `main`
